# LCNAF2Wiki

## Scope

Limit all work to the `LCNAF2Wiki-extension` folder. Do not read, edit, or run
anything outside it.

## README files

Do not edit any README file. This includes `LCNAF2Wiki-extension/README.md` and
`LCNAF2Wiki-main/README.md`. If a change needs documentation, tell the user in
chat and let them write it.

## Code comments

- Keep each comment to two lines and three sentences maximum.
- State what the code does and any constraint that is not obvious. Do not
  restate the code, explain history, explain design rationale, or give worked
  examples. Do not move design rationale into the README either.
- Use ASD-STE100 style: imperative for instructions, declarative for facts,
  one idea per sentence, plain words, no em dashes.
- Do not add comments to code you did not change.

## Attribution

Do not credit Claude, Anthropic, or AI assistance anywhere. This covers code
comments, file headers, commit messages, PR descriptions, changelogs, and
documentation. No "Co-Authored-By" lines, no "Generated with" footers.
